# Changelog

All notable changes to RECON-X are documented here.

## [1.0] - 2026-10-02

### Added
- ✅ Complete subdomain enumeration (crt.sh, DNS brute-force)
- ✅ Live host detection with HTTP/HTTPS probing
- ✅ Technology fingerprinting (servers, frameworks, CMS)
- ✅ Professional HTML report generation
- ✅ Multi-threaded execution for speed
- ✅ JSON output for all phases
- ✅ Beautiful hacker-themed interface
- ✅ Zone transfer attempts
- ✅ Reverse DNS lookups
- ✅ Status code detection
- ✅ Page title extraction
- ✅ Server header analysis

### Features
- Supports Windows, macOS, Linux
- Configurable thread count
- Modular architecture
- Comprehensive error handling
- Professional documentation

### Known Issues
- Zone transfers usually blocked on modern servers (expected)
- Large wordlists may consume memory
- Some domains timeout on first attempt
